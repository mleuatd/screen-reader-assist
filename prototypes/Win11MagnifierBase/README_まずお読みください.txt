Windows 11 3画面拡大鏡 v0.5（非アクティブOCR読み上げ対応・試作品）
2026年11月12日

【起動方法】
1. ZIPを展開してください（ZIPの中から直接実行しない）。
2. 「3画面専用拡大鏡」フォルダーへ進みます。
3. 「START_3画面拡大鏡.cmd」をダブルクリックしてください。
4. 拡大表示ウィンドウは3枚目のモニターを選んで表示できます。

【今回追加した機能】
■ Alt＋左クリック
  拡大鏡をアクティブにする必要はありません。
  クリック位置のテキストを取得し、見つからなければ周囲をOCRで認識して読み上げます。
■ Alt＋左ドラッグ
  画面1・2も含め、好きな画面でAltを押して左クリックし、そのまま斜めへドラッグ。
  黄色い四角い枠を離すと、枠内をWindowsの日本語OCRで文字認識して読み上げます。
  画像、スキャンPDF、選択できない文字も対象です（画像の意味の説明はしません）。
■ 速度設定
  前回のダブルクリック2回目＋左右ドラッグで変更した音声速度を引き継ぎます。
■ 無効化
  Alt＋左クリックは対象アプリの同じ操作と競合する可能性があります。
  画面上部の「Alt＋ドラッグ：範囲読み上げ」をオフにすると、通常操作へ戻せます。

【従来の機能】
  3画面専用の拡大表示／倍率変更／サイズ変更／最大化／スナップ／ドラッグ拡大。
  拡大画面上で1回ドラッグ→倍率変更、2回目を保持してドラッグ→音声速度変更。

【必要な機能】
  Windows 11 64bit / Windows PowerShell 5.1 / .NET Framework。
  日本語OCRがインストールされていること。
  読み上げには、System.Speechから使用できる日本語SAPI音声が必要です。
  日本語OCRと日本語音声は別々の機能で、PCによっては追加設定が必要です。

【注意事項】
  Windows 11実機でのコンパイル・動作確認は未実施です。
  OCRは間違って文字を認識することがあります。
  Alt＋左クリックはこのアプリ起動中のみグローバルに監視します。
  監視中に通常のAlt＋クリック操作と競合するため、必要なら機能をオフにしてください。
  選択領域は外部送信しません。画像・認識結果の一時ファイルは処理後に削除します。
  機密資料やパスワード表示画面での利用は慎重に判断してください。
  自動起動・常駐化・管理者権限の要求はしていません。

詳しくは「仕様書_v0.5_全画面Alt範囲読み上げ.md」をお読みください。
