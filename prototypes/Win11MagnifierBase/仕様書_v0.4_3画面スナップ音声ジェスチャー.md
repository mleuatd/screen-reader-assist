# Windows 11 独立型拡大鏡 v0.4 仕様書

作成日：2026年11月12日　状態：**Windows 11実機試験前の試作品**

## 1. 開発目的

Windows 11の日本語環境で無料で利用できる弱視者向け拡大鏡。通常の作業ディスプレイを2台、拡大映像表示用ディスプレイを1台という構成を想定し、3枚目の表示ウィンドウがWindows標準のウィンドウ操作に従うことを重視する。

## 2. 基本構造

- PowerShell 5.1からC#ソースをコンパイルするWinFormsアプリケーション。WindowsのMagnification APIを使用。
- 拡大鏡は、通常の枠とタイトルバーを持つ、サイズ変更可能な独立ウィンドウとして動作する。
- 初期起動時は3番目のモニターを優先して最大化。ユーザーは選択欄で別モニターを指定可能。
- 拡大元は通常のマウスがある作業画面。拡大先のモニターにマウスが入った場合、拡大元の位置を保持する。
- プレビューのクリックを作業画面のアプリケーションには転送しない。

## 3. マウスジェスチャー

| 入力操作 | 効果 | 変化量 |
|---|---|---|
| 1回目の左クリックを保持して右ドラッグ | 拡大 | 48pxにつき+10％ポイント |
| 1回目の左クリックを保持して左ドラッグ | 縮小 | 48pxにつき−10％ポイント |
| 素早く2回クリック、2回目の左クリックを保持して右ドラッグ | 読み上げ速度上昇 | 48pxにつき+1段階 |
| 素早く2回クリック、2回目の左クリックを保持して左ドラッグ | 読み上げ速度低下 | 48pxにつき−1段階 |

- ダブルクリックはOSのダブルクリック設定時間・距離を参照する。
- 最初のクリックでドラッグした場合、その操作は次のダブルクリックの1回目として数えない。
- ドラッグ途中でボタンを離した場合は終了し、実施済みの設定値を保持。
- 切替のドラッグはそれぞれチェックボックスで個別に無効化可能。
- 倍率：100～1600％。読み上げ速度：−10～＋10。音声は**アプリ内のSystem.Speech読み上げ**にのみ反映。
- 日本語SAPI音声が存在しない環境でも、拡大鏡の機能は動作継続できる設計。

## 4. Windows 11のスナップ連携（v0.4追加）

### 4.1 前提

Windows標準のスナップ機能に委ねる。アプリ側でシステムショートカットをフックせず、通常のトップレベルウィンドウ（`FormBorderStyle.Sizable`、最大化ボタンあり）として提供する。

### 4.2 期待する操作

| ユーザー操作 | 期待動作 |
|---|---|
| 拡大映像をクリック | 拡大鏡のトップレベルウィンドウをアクティブにする |
| Windows+左矢印 | 今いるモニターの左半分に配置 |
| Windows+右矢印 | 今いるモニターの右半分に配置 |
| Windows+左矢印 → Windows+上矢印 | 左上の4分の1などに配置（Windowsの状態遷移による） |
| Windows+右矢印 → Windows+下矢印 | 右下の4分の1などに配置（Windowsの状態遷移による） |
| Windows+Z | Windows標準スナップレイアウトを表示 |
| タイトルバーをダブルクリック | 同じモニターで最大化または復元 |
| タイトルバーを画面端・隅にドラッグ | Windows標準のスナップ候補に配置 |

Windows 11のスナップ設定がオフの場合はOS設定に従い無効になる。また、モニターの解像度やウィンドウの最小サイズによって一部の分割パターンが使えない場合がある。

### 4.3 サイズ変更時の追従

- ウィンドウの`SizeChanged`・表示エリアの`Resize`で拡大鏡コントロールの位置と寸法を再設定。
- 倍率・表示元の追従位置を原則維持。
- モニター移動によって表示元と表示先が同一にならないよう、表示先の現在位置はそのつど判定。
- スナップ操作中に画面全体へ入力イベントを注入しない。
- 別のモニターに移動して終了した場合は、実際の表示先を次回起動の既定先として保存。

## 5. 安定性・安全性の原則

1. Windowsの拡大APIを使用。GPUコンテンツ、保護映像、マルチDPIでの制限あり。
2. アプリ全体のマウス・キーボードフック、管理者権限、ドライバー追加は行わない。
3. 拡大画面に対するマウスドラッグだけを、自アプリのネイティブ子ウィンドウで検知。
4. 拡大処理が失敗した場合は追従を停止してエラー表示し、元のデスクトップ操作を変更しない。
5. 設定保存はドラッグ終了時。ドラッグ中に大量のディスク書き込みを行わない。
6. 音声合成が初期化できないときも拡大映像を使用可能な設計にする。

## 6. 実機検証が必要な項目

- Windows 11 64ビット／PowerShell 5.1でのC#コンパイル・起動。
- 3モニター（解像度・拡大率混在）の映像表示と移動。
- プレビュークリック後のWin+矢印、Win+Z、スナップレイアウト候補。
- 左右半分・4分の1配置での拡大コントロールのサイズ調整。
- 一度クリックしてドラッグ／ダブルクリックの2回目を保持してドラッグする操作の区別。
- OSにインストールされた日本語SAPI音声の検出・速度変更。
- 音声合成が使えない環境の起動・拡大処理。
- 連続使用時のCPU・GPU・メモリ負荷、DPI混在時のカーソル座標。
- モニター抜き差し時の動作・ウィンドウの復旧。

## 7. 未実装・対象外

- 拡大プレビューから元のアプリへクリックを転送する操作。
- 任意の他社アプリやOS全体の音声／YouTube音声速度を変更する機能。
- テキストを自動検知して読み上げるOCR・スクリーンリーダーの統合。
- タッチパネルのピンチ・長押しなどの専用ジェスチャー。
- Windows標準拡大鏡の内部処理との完全互換性。
