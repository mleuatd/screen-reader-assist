# Win11MagnifierBase — 3画面拡大鏡（別系統試作）

このフォルダーは、2026-11-12 時点の **Win11MagnifierBase v0.5** の原本です。
既存の `src/ScreenReaderAssist/`（.NET 8/Windows Forms）とは**別実装**として保存しています。既存アプリとの統合や置き換えは行っていません。

## 主な設計
- 画面1・2を通常の作業領域、画面3を独立した拡大表示領域として使う。
- 拡大映像のタイトルバーをダブルクリックすると、そのモニター上で最大化する。
- Windows 11スナップ、ウィンドウサイズへの表示追従。
- 拡大映像上の単一ドラッグで倍率変更、ダブルクリックの2回目を保持した左右ドラッグで音声速度変更。
- Alt＋左クリックで位置の文章を読み上げ、Alt＋左ドラッグで矩形選択してWindows OCRで認識した文字を日本語で読み上げる（他のアプリがアクティブでも利用する想定）。

## 起動（試作）
`3画面専用拡大鏡/START_3画面拡大鏡.cmd` をWindows 11で実行。
PowerShell 5.1 / Windows日本語OCR / 使用可能な日本語SAPI音声が必要です。
詳細は `README_まずお読みください.txt` と `仕様書_v0.5_全画面Alt範囲読み上げ.md` を参照。

- 配布元: この会話で作成した `Win11MagnifierBase_v0.5.zip` のテキストソース一式。
- **Windows 11実機ビルド／GUI操作／3モニター／OCR／グローバルマウス入力の動作検証は未実施。**
