# Windows 11 3画面拡大鏡 v0.5：Alt＋範囲選択／日本語OCR読み上げ

## 目的

画面1・2でExcel、エクスプローラー、ブラウザーなど別のアプリを使用しているときも、拡大鏡をアクティブ化せずに、マウスで囲んだ文章を日本語で読み上げる。画像やスキャンPDFなど、選択できない文字にも対応する。

## v0.5での操作

| 操作 | 動作 |
|---|---|
| Alt＋左クリック、すぐ離す | その位置のテキストをUI Automationで探し、取得できなければクリック位置の周辺（最大740×155ピクセル）をOCRで認識して読み上げる |
| Alt＋左ボタンを押しながら任意方向へドラッグ | 黄色い枠で長方形を指定。離すとその範囲をキャプチャしてWindows標準OCRで認識し、日本語音声で読み上げる |
| Altを使わず、拡大映像の上で通常の左ドラッグ | これまでどおり右へ10％ポイントずつ拡大、左へ10％ポイントずつ縮小 |
| 拡大映像の上でダブルクリックし、2回目のクリックを保持して左右へドラッグ | これまでどおり読み上げ速度を変更 |
| 「Alt＋ドラッグ：範囲読み上げ」のチェックを外す | グローバルなAlt＋左マウス操作の監視を一時的に無効化 |
| Esc（ドラッグ中） | 範囲選択を取り消す（画面描画の更新タイミングに依存） |
| 停止ボタン | 読み上げ中の音声を停止 |

**読み上げ対象：** 一般のアプリ画面に表示されている文字、画像内の文字、PDFの画像化された文字など。画像の意味をAIで説明する「画像解説機能」ではない。OCR精度は元画像の解像度、色、文字方向などに依存する。

## 3画面／非アクティブ動作

- メインの拡大鏡ウィンドウは、画面3に置いたままでよい。
- マウスは画面1・2など任意のデスクトップ画面で操作する。
- グローバル低レベルマウスフックで「Altを押しているときに始まった左マウス操作」のみを監視する。
- このジェスチャー中のマウスボタンと移動を元のアプリへ渡さず、誤ドラッグを回避する。**他アプリ固有のAlt＋左クリック操作とは競合するため、必要ならチェックを外して無効化する。**
- グローバルマウスフックはアプリ終了時に必ず解除する。管理者権限、外部ドライバー、マウス入力の合成は必要としない。
- 選択範囲は透明な最前面ウィンドウ上の黄色い矩形で表示する。透明表示が環境によって使えない場合は実機で追加の調整が必要。

## 読み上げと認識処理

1. Alt＋クリックのみなら、UI Automation の TextPattern / ValuePattern で短い文章を先に取得する。見つからなければ周囲をスクリーンショットする。
2. Alt＋ドラッグなら、囲まれた領域をスクリーンショットする。
3. 黄色い選択枠を消してから、バックグラウンドで一時PNGを作る。
4. 同梱の `RecognizeSelection.ps1` が Windows 11 のローカル `Windows.Media.Ocr` で日本語OCRを行う。
5. 文字列を元のv0.4の `System.Speech.Synthesis.SpeechSynthesizer` に渡し、既存の速度設定で再生する。
6. 一時PNGとOCR出力ファイルは処理後に削除する。画像・文章を外部へ送信せず、クリップボードにも触れない。

OCR処理の待機時間は最大18秒で打ち切る。OCRに失敗しても拡大鏡本体を停止しない。処理中の連続OCR要求は受け付けず、処理終了後に再試行できる。

## Windows 11の前提

- Windows 11 64bit、Windows PowerShell 5.1、.NET Framework 4.x。
- **日本語OCR言語機能** がインストールされていること。確認・追加場所：設定 → 時刻と言語 → 言語と地域 → 日本語の言語のオプション。環境によっては日本語OCR機能が未インストール。
- **日本語SAPI音声** が使用できること。PCに日本語表示言語があってもSystem.Speechの音声一覧に日本語音声がない場合、認識だけ成功し読み上げられない。この場合、認識結果をアプリ内の文章欄に表示する。
- 複数モニターで表示倍率（DPI）が異なる場合は、描画位置・座標の一致を実機で確認する。
- 管理者権限のウィンドウ、セキュリティデスクトップ、コピー保護された動画、表示が保護されている画面は取得できない場合がある。

## 起動

ZIPをWindows 11で展開して、`3画面専用拡大鏡/START_3画面拡大鏡.cmd` を実行する。ソースコードからその場でコンパイルする方式なので、実行に時間がかかることがある。PowerShellの「ExecutionPolicy Bypass」はこの起動プロセスに限る。

**注意：** 動作の実機確認は未実施。Windows 11環境でのソースコンパイル、OCR認識、UI Automation取得、Alt＋ドラッグ捕捉、複数モニター表示、および長時間の安定性は検証が必要。今回のファイルは開発中の試作品であり、実用上の動作保証はしない。

## 将来の課題

- OCR認識精度の評価：縦書き／小文字／高DPI／白文字、テーブルや複数段組みなど。
- 画像データの外部送信なしで、ローカル画像説明を実装できるか検討。
- 任意のショートカットやジェスチャーへの変更、Altとの競合解消。
- 非SAPI日本語音声（WindowsのOneCore音声等）の対応。
- ドラッグ枠の音声ガイド、範囲確定時の効果音、読み上げ対象のプレビュー。
- Windows 11実機でのメモリ・CPU負荷とグローバル入力への影響の測定。
