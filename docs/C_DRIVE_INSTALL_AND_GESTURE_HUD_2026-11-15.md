# Windows 11・Cドライブ専用インストール（2026年11月15日）

本ソフトは **64ビット専用** のため、インストール先は必ず **`C:\Program Files\日本語拡大鏡`** とします。32ビットアプリ用の `Program Files (x86)`、および存在しないDドライブは使用しません。

## インストールの手順

1. GitHubの試用版リリースから小さい `JapaneseMagnifier-CDrive-Installer.zip` を取得。
2. ZIPをすべて展開し、**`日本語拡大鏡_インストール.bat`** をダブルクリック。
3. Windowsのユーザーアカウント制御（UAC）画面でインストールを許可。
4. インストーラーがGitHubの公式公開済みZIPを取得、必須ファイルと日本語ONNXモデルを確認し、Cドライブの所定のフォルダーに設置。
5. デスクトップの **「日本語拡大鏡」** ショートカットから、以後は管理者権限なしで起動する。

本体ZIPの公開配布ページ：https://github.com/mleuatd/screen-reader-assist/releases/tag/tryout-20261115-hud

## 設定・更新・オフライン

- `ScreenReaderAssist.exe` や `magnifier\` フォルダー、日本語モデルは `C:\Program Files\日本語拡大鏡`。
- 更新時は既存のインストールフォルダーを別名で退避し、問題なく動くまで残す。失敗時は元に戻す。
- `settings.ini` の保存先は、インストール版では **`%LOCALAPPDATA%\日本語拡大鏡\settings.ini`**。パスワードや画面内容は保存しない。ポータブルZIPを直接展開して使う場合は従来どおりEXE隣に保存。
- 3画面拡大鏡の既存設定はAppData、両アプリの読み上げ速度同期は `%LOCALAPPDATA%\ScreenReaderAssist\voice-rate.shared` の整数のみ。
- **ネットが必要なのは最初の配布ZIPの取得・インストール時だけ**。普段の拡大表示、画面OCR、日本語音声合成にクラウドOCRやネットワーク通信は使用しない。
- ZIPはGitHubから直接落とすものであり、モデルや音声データをPC外に送信しない。

## 中央オーバーレイ・音声調整

- 拡大表示を**1回押したまま左右へドラッグ**：中央に大きい倍率バーと実倍率を表示。指を離したら短時間後に消える。
- **ダブルクリックの2回目を押したまま左右へドラッグ**：中央に音声速度のバー（−10～＋10）を表示。
- この音声速度操作を始めると日本語の**「テスト再生」**を繰り返す。ドラッグで速度を変えたら、その速度で再生し直す。**指を離した瞬間にループ再生を停止**し、設定を保存。
- 読み上げ速度はもう一方のC# OCRアプリとも共有。画面枠はユーザーが望む見やすい緑色。
- 画面の倍率と音声速度の表示はマウス操作を妨げないクリック透過のオーバーレイで、Windowsのシステム全体の拡大率を変更しない。

### 未実機検証
C#コンパイルテストはWindows CIで行うが、表示の重なり、実際のマウスジェスチャー、音声の発声間隔と3モニター動作は利用者のWindows11実機での検証が必要です。日本語SAPI音声がPCに存在しなければ試聴はできません。その場合でも拡大機能は使用可能です。
