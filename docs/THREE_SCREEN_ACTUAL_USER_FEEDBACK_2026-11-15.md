# Windows 11の3画面実機報告：調査と修正（2026年11月15日）

## 実際の配置
- ノートPCの内蔵ディスプレイ：タッチ入力あり。
- HDMI外部ディスプレイ：タッチ入力なし。ここに3画面専用拡大鏡を表示・最大化して利用。
- USB Type-C外部ディスプレイ：タッチ入力あり。
- Windows 11の「表示画面を拡張する」構成で、マウスがあるディスプレイを追跡。

## 確認した仕組みと修正
### 1. 拡大鏡の中にマウスを置いても映像が追従しない
元コードの`TickFollow`は、マウスが拡大鏡を表示しているディスプレイへ入ると直前の画像を保持する。これは自己再帰（映した画面をさらに映すこと）の防止策であり、現行設計では正常動作。画面全体の拡大率を変更する危険な処理は再導入しない。

**UI対策**：拡大鏡上部に「操作を大きく表示」ボタンを追加。倍率の増減と音声速度の増減を大きな日本語ラベルと大きな操作ボタンにした、独立した高コントラストの操作画面を開く。内部表示映像の再拡大ではなく、本物のWinForms操作部品を大きくする。

### 2. マウスを左右に動かしても倍率や速度が変わらない
従来のドラッグ判定は、ネイティブMagnifier子ウィンドウから送られるマウスメッセージに依存していた。そのウィンドウは通常のWinFormsイベントと同様に入力を届けるとは限らない。

**修正**：既存の`GlobalOcrSelection`のローレベルマウス監視（すでにインストール済み）を、**拡大鏡の画像表示領域で始まった左ボタン操作だけ**に利用。プレビュー以外のクリックやタッチ入力、通常のWindows操作は妨げない。ネイティブメッセージも代替経路として残す。右への移動で増加、左への移動で減少（24px/1段階）。ダブルクリックの2回目を押したまま左右へ動かすと読み上げ速度を変更し、中央HUDと「テスト再生」ループを利用する。

**注意**：Windows CIではC#コンパイルと左右24pxの計算を検証。HDMIを含む実際のマウスイベント配信・表示・音声再生の最終動作は現物で確認する。

### 3. マウスを置いただけで読み上げる
読み上げアプリの初期INIは`カーソルで自動読み上げ`。0.75秒程度静止でUI AutomationまたはOCRを使うため、Alt＋クリックをしていないのに読み上げる。

**修正**：`範囲選択のみ`を初期モードとし、独立した`カーソル自動読み上げを許可=いいえ`を導入。古い設定に`mode=cursor`が残っていても、**明示的なON設定がなければ自動読み上げは無効**。通知領域メニュー／設定画面から必要時だけ有効化可能。手動`Ctrl＋Alt＋R`・Alt＋右ドラッグは利用可能。

範囲選択の操作画面にあるマウス静止自動読み上げも既定OFFにした。`H`を押したときだけ有効になる。

### 4. Alt＋右ドラッグの緑枠選択が開始されない
旧コードはマウスDOWNをグローバルフックで抑制しながら、次のタイマーで`GetAsyncKeyState`がボタン押下中か確認していた。抑制イベントと状態照会が矛盾するため途中で選択が取消される可能性があった。

**修正**：DOWNを明確に受信したら、対応するUP／Esc／30秒の安全タイムアウトまでフックの状態を保持する。画面上の緑枠表示、入力の抑制、読み上げの選択範囲処理は維持する。OCR用`RecognizeSelection.ps1`の参照先は拡大鏡の同梱フォルダーから明示的に解決し、PowerShellの`System32`作業フォルダー誤認識を防止する。

### 5. OCRが遅い可能性のある部分
Alt＋右ドラッグ経路では、画面切り出し（`Graphics.CopyFromScreen`）、PNG化、Windows PowerShell 5.1の新規プロセス起動と日本語`Windows.Media.Ocr`、結果ファイル読み込み、日本語SAPI音声合成が続く。Windows APIの入力イベント待機、90msの枠消去待ち時間もある。

**今回追加した記録**：`%LOCALAPPDATA%\日本語拡大鏡\ocr-performance.log`に、スクリーンキャプチャ、PNG圧縮、PowerShell起動＋OCR、OCR全体の処理時間をミリ秒単位で保存。画像本体・文字内容・座標・認証情報を記録しない。

**まだ測っていない項目**：実際にマウスを離してから音が鳴る瞬間までの時間、タッチ入力時の表示遅延、実機3画面での応答時間。このログは特にボトルネックになりやすいPowerShell起動部分を把握するためのものであり、発声開始の時間とは区別する。

## 配布と実機確認
- GitHub mainへのマージはWindows CIのC#アプリ、3画面拡大鏡コンパイル、通信禁止検査、日本語OCRテスト、ZIP生成が全部成功した後に限る。
- 配布更新はデスクトップ「日本語拡大鏡を更新」から手動で実行（普段の拡大鏡・読み上げは完全オフライン）。
- 実際のWindows 11で、HDMIに最大化してから①プレビューの左ドラッグで倍率、②ダブルクリック2回目のドラッグで音声速度と試聴、③Alt＋右ドラッグの緑枠、④非意図的な読み上げ停止、⑤大きな操作画面のボタンを検証する。
