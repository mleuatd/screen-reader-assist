Screen Reader Assist
ダウンロード無料で体験設定作成使い方

Windows 11 / 個人利用無料 / 日本語優先

カーソルを合わせて、
文字を聞く。

標準モードではWindowsの文字情報を読み取り、取得できない文字も設定により画像OCRを試せます。通常OCRが失敗した場合は文字らしい範囲を自動検出し、拡大・補正して再試行します。漫画の吹き出しをクリックする試験モードや、一時拡大も搭載する開発中のアクセシビリティアプリです。

Windows用試用版をダウンロード

v0.6.5-preview.1 の試用版を公開中です。Windows上での画面操作・音声・拡大は未検証のため、正式版ではありません。アプリは署名されていないため警告が出る場合があります。

まずはブラウザで無料体験

アプリをインストールせず、スマホやパソコンで、範囲読み上げ・漫画の吹き出し読み上げ・3回タップ拡大を試せます。声の高さや読み上げ速度も設定できます。

インストールせずに体験する

サンプル画面の模擬OCRです。音声は端末のブラウザ機能を使用し、Windows全体の画面読み取りは行いません。

設定してWindows版ZIPを作る

この画面の設定がsettings.iniになります。セクション名・項目名・オン／オフも日本語で保存します。Windows用ZIPに実行ファイルと一緒に入れてダウンロードできます。文字はメモ帳で直接編集できます。設定内容や取り込んだZIPはサーバーへアップロードしません。

使い方：下の項目を設定して「設定済みZIPを作成」を押してください。ブラウザが公式ZIPを取得できない場合は、上のWindows用ZIPを一度ダウンロードして、下の枠にドラッグしてください。

基本操作
標準（自動カーソル）
アプリ常駐中、約0.75秒カーソルを止めると文字を読み上げます。まずWindowsの文字情報、必要ならOCRで補います。クリック操作には介入しません
漫画モード
カーソル付近の吹き出しと思われる部分をOCRして読み上げます（試験版。自動的なコマ順推定には未対応）
Ctrl + Alt + R
画面上の専用選択モードを開き、タッチ・ドラッグまたはキーボードで範囲を決めて読み上げ。1回タップで周辺を読む
Alt + Shift + M
漫画の吹き出しをクリックしてOCR（簡易検出・試験版）
Alt + Shift + U
現在フォーカス中のUI Automation文字を読む
Alt + Shift + S / P
停止 / 一時停止・再開
Alt + Shift + Z
画面拡大の開始・終了（試験的）
読み上げモードはWindowsアプリの設定からも切り替えられます。設定ファイルで読み上げモードや待ち時間も編集できます。画像OCRや漫画の解析は実機での精度検証が必要です。
画像や保護されたゲームの文字は読み取れない場合があります。無料のWindows音声合成で日本語音声がない場合は、Windowsの言語・音声設定を確認してください。

    
オフライン処理・プライバシー優先。公開ソースの初期試作です。声優本人の音声を学習・複製する機能はありません。
