# Screen Reader Assist — Windows 11 視覚障害支援アプリ（試作 v0.6.4）

**[インストール不要でブラウザ体験（スマホ・PC）](https://raw.githack.com/mleuatd/screen-reader-assist/main/site/demo.html)** | [Web設定画面（GitHub経由）](https://raw.githack.com/mleuatd/screen-reader-assist/main/site/index.html)


画面の任意範囲からWindowsの日本語OCRで文字を取り出し、インストール済みの音声合成エンジンで読み上げる、常駐型オープンソースアプリの**試作ソースコード**です。

> **検証状況（2026-10-11）:** GitHub Actions のWindowsビルド・ロジックテストとWeb設定テストが成功。`win-x64` の配布アーティファクト生成を確認済み。v0.5のWindowsビルドと43件のロジックテストに成功。Windows GUIでの操作、ゲーム・漫画OCR・タッチ入力などの実機検証は未実施。GitHub Releases 最新プレビュー v0.6.4-preview.1 を公開済み。GitHub Pagesは初期有効化待ちですが、無料のGitHubファイル表示サービスで公開体験版を利用可能。試作版につき未検証機能に注意。

## 主な機能（実装済みコード／動作未検証）

- 通知領域に常駐。起動時は設定ウィンドウを隠します。
- `Ctrl + Alt + R`: マウスドラッグまたは矢印キーで範囲指定してOCR・読み上げ。
- `Alt + Shift + M`: 吹き出し内部をクリックし、明るい連続領域を推定してOCRする **実験的** 漫画モード。
- `Alt + Shift + U`: フォーカス中のUI Automation要素の文字取得。
- `Alt + Shift + S`: 読み上げ停止。`Alt + Shift + P`: 一時停止・再開。
- `Alt + Shift + Z`: Windows Magnification APIによる一時的な画面拡大切り替え（実験的）。
- 他アプリへの干渉を避けるため、グローバル3回クリック検出を廃止。範囲読み上げでは専用の最前面画面でのみ操作を受け付けます。
- 音声の種類・速度（-10〜10）・音量（0〜100）・倍率を設定画面から変更。
- 実行ファイルと同じフォルダーの設定INIを読み書き。Web上でINIを編集し、既存ZIPを取り込んで設定済みZIPとして再出力できる。

## 必要環境

- Windows 11 Home x64
- OSにインストール済みのOCR言語（日本語が推奨）
- Windowsにインストール済みのSAPI対応読み上げ音声（日本語推奨）
- ソースから開発する場合は .NET 8 SDK とインターネット経由の公開NuGet取得（`System.Speech` 8.0.0）

## ビルド

```powershell
dotnet restore src/ScreenReaderAssist/ScreenReaderAssist.csproj
dotnet build src/ScreenReaderAssist/ScreenReaderAssist.csproj -c Release
dotnet run --project tests/ScreenReaderAssist.Tests/ScreenReaderAssist.Tests.csproj -c Release
dotnet publish src/ScreenReaderAssist/ScreenReaderAssist.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

`publish/` 以下の成果物を配布します。リポジトリにプッシュするとGitHub Actionsの`windows-build.yml`が自動ビルド・スモークテストを行い、成功した場合にZIPがワークフローのアーティファクトとして添付されます。`v*` タグを作成した際は`release.yml`がGitHub Releasesを作成します（権限設定等が必要）。

## 操作方法

1. アプリを起動。通知領域にアイコンが出る想定です。
2. `Ctrl + Alt + R` を押す。
3. 元画面のスクリーンショットを表示する専用画面が前面になり、その中を指またはマウスでドラッグして離す。1回タップならタップ周辺（最大360×160px）を読む。キーボードでは矢印キーで移動、Shift+矢印キーで範囲を拡大・縮小、Enterで確定、Escでキャンセル。
4. OCR結果が読み上げられる。読み上げ停止は `Alt + Shift + S`。
5. 設定の変更は通知領域アイコンをダブルクリック。

一部のゲーム、保護コンテンツ、UAC画面、排他的フルスクリーンでは画面の取得に失敗する可能性があります。ホットキーも他のアプリと競合する場合があります。

## 設定Webサイト

`site/index.html`を静的配信することで使用可能です。データはブラウザ上で生成され外部送信されません。Webサイトでは日本語の設定INIを保存するか、設定入りWindows用ZIPを生成できます。旧英語INI・旧JSONもWebから取り込めます。ブラウザから実行中のアプリへ直接変更を反映する方式は**未実装**です。

音声速度は`rate: -10〜10`（System.Speech API）であり、倍率ではありません。設定形式の詳細は [`REQUIREMENTS.md`](REQUIREMENTS.md)。

## 開発上の重要な制約

- 漫画の検出アルゴリズムは**白っぽい領域の連結成分推定**で、吹き出し境界を機械学習で検出していません。縦書き漫画OCRの品質も未測定です。失敗した場合は通常の範囲選択を使ってください。
- Windows標準OCRには最大画像サイズや言語の制約があり、画像の縮小処理を実装しています。縦書き読み順の補正は未実装です。
- 拡大中の入力座標を補正する`MagSetInputTransform`は未実装。通常クリックとの競合やマルチモニター時の動作に注意してください。3回クリック機能は既定で無効です。
- 音声モデルの追加や声質合成機能は未実装です。本人の声の許諾のないクローン音声の学習は行いません。
- 文字・画面画像をクラウド送信するコードはありません（アプリのビルド時NuGet取得は別）。
- Windowsの`System.Speech`にはWindowsに対応した音声が必要です。

## v0.2 入力操作変更（Ctrl+Alt+R）

- `Ctrl+Alt+R`の一度の同時押しで専用の全面選択フォームを起動。キーを押し続ける必要はありません。直前の画面を画像として表示し、指・マウス・キーの入力は選択フォームで受け取ります。
- ドラッグして離すと囲んだ座標をOCR。短いタップの場合は周辺（最大360×160ピクセル）をOCR。Escで中止。
- 選択中は通常アプリにクリック操作が伝わらないことを意図した構造ですが、UACセキュアデスクトップ、排他的フルスクリーン、他のTopMostウィンドウ等の特例があります。実機での入力非干渉テストは未完了。
- 以前の設定ファイルの`magnifier.enableTripleClick:true`は読み込み時に無効化。グローバル3連クリックフックは使用しません。
- 対応バージョンは次のプレビューリリース以降です。旧`v0.6.4-preview.1`はホットキーが違います。

## v0.3 カーソルを止めて読み上げ（試作）

- `Ctrl+Alt+R`で元画面の画像を表示する専用の選択モードに入る。ブラウザ・YouTubeのリンクの上をクリックしても、リンク操作は下層へ送らない設計。
- カーソルを約850ミリ秒止めると、周辺画像のOCR結果から位置の近い文字行を読み上げる。
- 短いクリック/タップは近い一行、ドラッグは囲んだ範囲の全文を読み上げてモード終了。
- 読み取りモード中の`H`で自動読み上げON/OFF、`Esc`で終了。モードを終了すれば通常操作へ戻る。
- 移動中に完了した古いOCR結果は破棄し、同じ文章を連続して読み上げない。ホバーだけでクリップボードは書き換えない。
- **制限**: モード開始時の静止画像を読んでおり、実リンク先URLの取得ではない。1行判定なので折り返した長い動画タイトルは途中までになる場合がある。Windows GUI上の安全性は実機未検証。

## v0.4：複数の読み上げモード
- **標準：カーソルで自動読み上げ**。Windowsアプリ常駐中にカーソルを約750ミリ秒止めると自動で読み上げます。クリック・フォーカス変更・全面オーバーレイを使用しません。
- **デジタル文字優先**：Windows UI Automationで取得できる文字情報を優先。取得できなければ、既定では近くの画面画像をWindows OCRで解析します。設定でOCR補完を無効化するとデジタル文字だけを読みます。
- **漫画モード**：カーソル付近の画像から白い吹き出し領域を推定し、その中の文字をOCRする試作です。漫画全ページのコマ割りと会話順の自動判定は未実装。
- **範囲選択のみ**：自動カーソル読み上げは停止。Ctrl+Alt+Rから従来の範囲指定が可能。
- **自動読み上げ停止**：自動カーソル読み上げを停止。手動ホットキーは引き続き利用可能。
- 通知領域のアイコン右クリック→「読み上げモード」、またはアプリの設定画面で変更できます。
- 静止待ち時間400～2000ms、OCR補完の有効・無効、音声速度などを編集し設定ファイルへ保存できます。
- 自動カーソルは100msタイマーで位置だけを監視。読み上げ中にカーソルが移動すれば古いOCR結果は捨て、同じ文章の重複朗読を抑制します。
- **制限**：画像になった文字にもOCRは試せますが、低画質や縦書きでは認識精度が下がります。Windows実機でのUIA取得・カーソル位置・音声・漫画の精度はまだ未検証です。

### デジタル文字を取得する方式
Windows UI Automationを優先し、取得できない場合はWindows標準のMicrosoft Active Accessibility（MSAA）も試します。両方で取得できない場合だけ、OCR補完がONなら画像を認識します。アプリのクリックを自動実行することはありません。

## v0.4.1 画像から文字らしい範囲を自動推定してOCR再試行
- Windows UI Automation、MSAAのデジタル文字情報を優先。文字情報がない場合は通常のWindows OCRを試す。
- 通常OCRが見落とした場合に、画面内の明暗エッジが集まる領域をテキスト候補として最大2個抽出。
- 候補を切り抜いて最大2倍に拡大し、コントラストを補正してWindows OCRを再試行する。
- 認識文字が得られた場合に限って発声。OCRの結果がない画像から架空の文字列を推測して読み上げる機能ではない。
- 通常の自動カーソルモード、漫画モード、手動で選択した領域の読み上げで利用可能。画像OCR補完をオフにすればデジタル文字読み上げのみになる。
- 文字の境界を画像処理で推定する軽量な実験アルゴリズムであり、学習済みモデルによる高精度な吹き出し・文脈認識ではない。実際の漫画の縦書きや極小の文字、低解像度テキストの精度は未検証。

## v0.5 認識済みテキストから音声へ：処理最適化

- `SpeechService` のSAPIエンジンは1回だけ作成。音声一覧を起動時に1回取得してキャッシュ。
- 同じ声・音量・話速が続く限り、`SelectVoice`、`Rate`、`Volume` の再設定をしない。声や設定を変えた場合だけ再設定する。
- `SpeakAsync`を利用し、音声合成・再生はSAPIの非同期処理に渡す。新しい文章が来たら古い再生を取り消す（前回と同じ動作）。無効な音声名はインストール済みの日本語音声等へフォールバック。
- 自動試験では偽音声エンジンに1万件渡した際の設定変更回数と処理時間を測定。これは音声生成時間ではない。
- Windowsランナーで利用可能なら、実際のSAPI音声をWAVデータに合成し、発声時間を含まない処理時間・文字数/秒を計測する。
- 音声の「合成計算時間」と「発声している秒数」は別。話速の変更は主に後者。CPU、Windows音声エンジン、音声言語によって計測結果は変わる。
- 本機能は日本語音声エンジンの変更やオンライン音声生成を行わない。視覚障害者向けの既存のローカル処理を維持。

## 日本語音声を確認した結果（2026年10月11日）
- **SAPI音声**：GitHubのWindowsランナーには英語2種類のみ（David Desktop、Zira Desktop）。日本語SAPI音声0種類。音声パックの導入は5分でタイムアウトし、未導入のまま。
- **Windows OneCore音声**：英語3種類（David、Zira、Mark）、日本語0種類。SAPIとOneCoreは異なるため、音声一覧を区別して検査済み。
- **したがって日本語の実波形生成速度や発音品質は未計測**。英語の17.8ms等の値を日本語の値に転用しない。日本語の文章サンプル3種類×話速3段階で、見つかった日本語SAPI音声すべてをWAV生成するテストコードを追加。
- Windows 11で日本語音声が使用可能な環境向けに、アプリの設定画面の「日本語音声を診断」ボタンと通知領域メニュー「日本語音声の性能を検証」を追加。非再生のWAV生成時間を測り、`%LOCALAPPDATA%\ScreenReaderAssist\JapaneseVoiceDiagnostic.txt`に結果を保存する。音声を耳で聞いたときの感想・遅延の実測ではない。
- 本機能では個人の画面や音声データを外部送信せず、ローカル音声エンジンだけで計測する。診断ボタンを押すまでは追加の計測負荷なし。

## v0.6 EXE + settings.ini の持ち運べる配布構成

- アプリはC#／.NET 8 Windows Forms製。配布ZIPの中身は`ScreenReaderAssist.exe`と同じ階層に`settings.ini`を置きます（自己完結型Windows版のため同フォルダーに補助DLL等がある場合もあります）。
- INIはUTF-8で、`[reading]`・`[speech]`・`[ocr]`・`[magnifier]`の項目をメモ帳で編集できます。独自の追加ソフトは不要。
- 起動時は`AppContext.BaseDirectory/settings.ini`を優先。古いJSON設定を使っていた場合はINIがなければ`%LOCALAPPDATA%/ScreenReaderAssist/settings.json`から設定を読み、保存時はEXE横の`settings.ini`へ移行します（JSONは削除しない）。
- アプリの設定ウィンドウからの保存・インポート・エクスポートもINIが基本（旧JSONの取り込みも可能）。
- **Web設定画面**：`settings.ini`のみ保存／コピー、既存INI・JSON・Windows用ZIPのドラッグ＆ドロップ読込、INIの編集、設定済みWindows版ZIPの出力に対応。
- Web画面は公式ZIPの自動取得を試行しますが、ブラウザのCORS制限で失敗する環境では、`Windows用試用版をダウンロード`で公式ZIPを先に保存してWeb画面にドラッグ＆ドロップしてください。それ以降は同じ画面内で設定を編集してZIPとして保存できます。
- ZIP生成はページ内のMITライセンスJSZipを使用し、データやINI内容をWebサーバーにアップロードしません。ただし公式ZIPのダウンロードはGitHubから行います。
- 持ち込んだZIPには任意の実行ファイルを含められるため、実行するファイルは必ず公式の配布ZIPなど信頼できるものを使用してください。
- 注意：インストール先フォルダーが書き込み禁止ならINIの上書き保存は失敗します。解凍した書き込み可能なフォルダーで実行してください。

## Webの音声速度スライダー
Web設定画面は速度のスライダーを大きく表示し、遅い（-10）・標準（0）・速い（+10）を明記。21段階で`settings.ini`の`[speech] rate`に書き出します。矢印キーやタッチ操作でも変更可能。標準に戻すボタンと現在値表示があります。SAPIのrateは音声合成エンジン固有の段階値であり、単純な1.5倍速等には対応しません。

## v0.6.1 日本語で編集できるINI

`settings.ini`はすべてのセクション名・項目名が日本語になりました。
- `[基本設定]`：`設定形式のバージョン=1`
- `[読み取り動作]`：`読み取りモード=カーソルで自動読み上げ`、`カーソル停止時間（ミリ秒）=750`、`画像の文字も読み取る=はい`
- `[音声読み上げ]`：`読み上げ速度=0`、`音量=100`、`使用する音声名=""`
- `[文字認識]`：`認識した文字をコピー=いいえ`、`前回の読み取り範囲を再利用=いいえ`、`日本語の文字認識を優先=はい`
- `[画面拡大]`：`拡大倍率=2`

メモ帳から編集できます。値は日本語の`はい／いいえ`や`オン／オフ`、数字には全角数字（例：`８０`）も利用できます。区切り記号の `[ ]` と `=` は半角のままにしてください。英語名の旧INIを読み込むことも可能で、書き出し時に日本語形式へ変換します。**日本語のINIファイルは新バージョンのEXEと組にして使用**してください。旧EXEは日本語キーを認識しません。

## v0.6.3 実機不具合調査用ログと設定画面のリアルタイム診断

- `ScreenReaderAssist.exe` 起動時に**同じフォルダー**へ `ScreenReaderAssist.log` を自動作成。以降、読み取り・音声再生中は設定画面が隠れていても継続記録。
- ログは日時付きUTF-8テキスト。約2MBに達すると `ScreenReaderAssist.previous.log` に古いログを退避。専用ソフト不要でメモ帳で開けます。
- 起動と二重起動、Windowsのホットキー登録成否・Windowsエラー番号、`Ctrl+Alt+R`の受信、範囲選択画面表示・キャンセル、OCR開始/成功/失敗・経過時間・文字数、カーソル静止、SAPIへの読み上げ要求/開始/完了/キャンセル、例外を記録します。
- 設定画面の**「動作状況（リアルタイム）」**タブはログを実時間表示します。画面上部の「状態」には自動読み上げの稼働状態と`Ctrl+Alt+R`の登録状態を表示。設定画面表示中は誤動作を防ぐため自動カーソル読み上げは一時停止する既存仕様を維持。
- 設定画面の「動作ログを開く」でログファイルをメモ帳などで開けます。「ログをコピー」で最近の診断記録をコピーできます。通知領域メニューにも「動作ログを表示」を追加。
- **「音声テスト」**ボタンと通知領域の同名メニューを追加。画像OCRを使わずに固定の日本語テスト音声を再生し、SAPIの再生開始や失敗をログで確認できます。
- **プライバシー:** 画面の画像、OCRで読んだ文章、クリップボード内容、表示中のサイトURL、カーソル座標は診断ログに保存しません。ただしWindows/.NET例外メッセージにはファイルパスなどの環境情報が含まれる可能性があります。ログ共有前に確認してください。
- **ログ書き込み権限:** EXEを読み取り専用のフォルダーに置くとログ保存に失敗します。書き込み可能な場所へZIPを解凍してください。失敗時は設定画面の稼働状態にエラーを表示します。
- `Ctrl+Alt+R`は静止画ベースの範囲選択画面を起動し、**そこでクリック・ドラッグ・Enterを押すとOCR**します。押しただけで必ず音声が出る仕組みではありません。何も起きない場合はログでホットキー登録/画面表示を確認します。

## v0.6.4：Ctrl+Alt+Rの開始音・終了音

- `Ctrl+Alt+R`で範囲選択モードを受け付けた直後に、**高く上がる二音**を鳴らします。
- 範囲選択のオーバーレイを終了した直後に、**低く下がる二音**を鳴らします。クリック/ドラッグで確定した場合も、`Esc`で取り消した場合も終了音が鳴ります。
- 終了音はOCRや音声合成の結果を待たず、範囲選択モードが閉じたことだけを知らせます。音声読み上げの終了を示す音ではありません。
- 各音は約185ミリ秒。C#で生成した異なるWAV波形を`System.Media.SoundPlayer`で非同期再生します。音声合成のSAPIや日本語音声の有無には依存しません。ネットワーク通信も追加データファイルも不要です。
- 二重操作で範囲選択が既に進行中の場合は、新しい開始音を出しません。音声再生に失敗した場合でもOCRとホットキーは動作を継続し、`ScreenReaderAssist.log`の`[操作音]`に成功要求・例外を記録します。
- 自動テストはWAV形式・サンプルレート・2種類の波形・短い長さを検証します。実Windows 11のスピーカー・音量・オーディオ出力で聞こえるかは未確認です。
